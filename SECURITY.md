# Security and private data

Do not include API keys, passwords, tokens, private conversations, recordings,
personal configuration or model credentials in commits or public issue reports.
Use synthetic examples and placeholder credentials to reproduce a problem.
Local user configuration and histories belong outside the source repository.

For a security vulnerability, use the public repository's **Security → Report a
vulnerability** feature for a private report. For ordinary defects, use Issues
with a minimal example that contains no private data.
