## Metafolder source selection — October 13

The public [Metafolder 1.2.1 source](https://github.com/ManoloRemiddi/DSH-Metafolder-Plugin/tree/a5332d902e147e824231a5470d3e2822b9288719)
is pinned to **a5332d902e147e824231a5470d3e2822b9288719**. Its complete
[MIT licence](https://github.com/ManoloRemiddi/DSH-Metafolder-Plugin/blob/a5332d902e147e824231a5470d3e2822b9288719/LICENSE)
and Copyright 2026 Manolo Remiddi were inspected. The 1,173-line `client.js`
is the dynamic-Cordis source of truth; `lib/client.js` is its generated module
wrapper. Both use React 18 and the older DSH workspace/sidebar services. A private
public-source research checkout is retained; no private repository source or
owner grouping data is copied into application code or tests.

The client contains the original colored group UI, named/collapsible groups,
workspace/session assignments, pointer drag, create/rename/delete/ungroup,
Workspace/Flat and Manual/Updated views, search, directory picking and real
workspace/session actions. The public package stores `dsh.wsmeta.v1` in browser
localStorage. Its optional Host service is in-memory; durable cross-device storage
is absent. Physical workspace moves are guarded and must remain guarded.

The Pi binding must supply the actual services the original component consumes:

- Session list `{ids, byId, current}`, status/pending interactions, open/create,
  search/fork and a binding for rename, using the current conversation/draft owners.
- Workspace list `{items: [{workspaceId, path, title, sessionIds}], archivedSessionIds}`,
  metadata create/adopt/rename/order/remove and archive, with current revisions.
- Slot registration, locale, layout and directory-picker faces; static build
  wrapping must preserve CSP and use the application's existing React instance.
- Read-only inspection must retain its narrower presentation and authority.
  Changing grouping is display metadata, never filesystem move permission.

The old client shadows the entire `sidebar.workspaces` seat. Mounting it unchanged
would risk hiding newer pin controls, archive confirmations, keyboard action
owners and retained draft/branch fencing. Preserve those existing features when
adapting its exact presentation; do not replace action owners with another SDK
loop or silently add model/tool requests. Its optimistic optional remote save and
localStorage lifetime are not an attested profile persistence contract. Any
persistence extension needs accepted values/revisions, failure visibility and
origin/restart qualification. The original local-only behavior must remain explicit.

Before copying/mounting, record selected/adapted hashes and complete notices, verify
the exact UI closure, exercise all original controls with independently authored
data and prove workspace paths/permissions/native histories stay unchanged. Keep
the original useful menu/keyboard behaviors; a narrower grouped list does not
satisfy this row. This source inspection establishes reuse feasibility, not
implementation, installed acceptance or complete plugin parity.
