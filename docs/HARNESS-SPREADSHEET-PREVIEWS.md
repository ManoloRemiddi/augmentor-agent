# Original Harness spreadsheet previews

## Registration, original UI and limits — October 12

The original public DSH spreadsheet registration serves `.xlsx`, `.xls`, `.csv`
and `.tsv` in the existing file sidebar. Its lazy renderer, FortuneSheet grid,
formula bar, sheet tabs, selection/copy controls, loading, Retry, notices and CSS
remain original. Editing and formula recalculation are disabled. Stored formula
results stay stored; missing cached results and unsupported workbook features
remain visible through the original warnings. CSV/TSV cells remain literal text,
including formula-looking strings and leading zeroes.

The public MIT GUI selection adds **twenty files**, bringing **507 to 527**, from
**d743267388641bc76f17c45ce8b4c231aed1d32c**: sixteen spreadsheet modules, the
original FortuneSheet licence and three original FortuneSheet/ExcelJS patches.
**Eighteen are verbatim; two carry marked adaptations.** `parse.ts` uses a fixed
same-origin module worker instead of a Blob worker. `xlsx.ts` omits an absent or
invalid optional default row height; the original multiplication produced NaN
and prevented scrolling in an otherwise valid workbook. Valid point heights
retain the original conversion. All preceding supplier bodies and CSS remain
unchanged; Apache-2.0 dsh-context remains **108 files**, with its separate notices.

The original parser retains **16 MiB**, **250,000 rectangular cells** across
sheets and a **15-second** deadline. The existing authorized complete-byte reader
and its independent **20 MiB** Host cap remain in use. Workbooks parse in a
dedicated browser worker; no Office conversion, agent, tool or provider request
is created. Source/version/authority checks and tab/session/Host lifetimes use
the existing original file viewer. Abort and timeout terminate the real worker.

The worker is one reviewed self-contained module at
`/dsh-excel-worker-0.2.1-alpha.2.mjs`. Its response policy permits only same-origin
scripts, with network and child workers disabled. The application policy is
unchanged. Parser code and the grid remain deferred from initial application
loading. Worker and application graphs both participate in supplier notices and
forbidden-backend/analytics checks.

## Dependency and licence provenance

Exact build-only pins are FortuneSheet core/react **1.0.4**, ExcelJS **4.4.0**,
fast-xml-parser **5.11.1**, PapaParse **5.7.0**, and SheetJS CE **0.20.3** from its
official CDN. SheetJS's tarball integrity matches the public DSH lock. SheetJS
is **Apache-2.0**; the other listed components are **MIT**. These dependencies do
not add installed production npm packages or native executables.

The three verbatim public patches apply to private build-local copies after
version, Git-blob source-identity and patch checks, retaining original/patched hashes in compiled
`SOURCE.json`. Workspace dependencies and selected releases are never patched.
Bare imports from those copies resolve against each original package location,
preserving nested dependency versions. ExcelJS uses its patched browser entry.
Successful builds remove only their own temporary overlay.

FortuneSheet's npm packages omit LICENSE; the exact original DSH FortuneSheet
MIT notice is selected and retained. The missing `@nodable/entities` **3.1.0**
text is recovered from its publisher commit
**ac48e7ea591da372be023a481875c747535812b3** and bound to its exact version and
SHA-256 in the reviewed catalogue. The prior 2.1.0 record remains unchanged.
Compiled notices retain each supplier's terms and attribution; neither Apache
nor the existing Office/PDF/font terms are relabelled MIT.

## Qualification and scope

The independently authored OOXML has two sheets, merge/style/number formatting,
a hidden row, a bottom row reached by real scrolling, absent and explicit row
heights, a deliberately incorrect saved formula result, a missing result and
unsupported conditional formatting. Raw BIFF8 records are independently authored,
not generated by the parser being tested. UTF-8 CSV and UTF-16 TSV exercise
literal values and encoding. No private or upstream document fixture is copied.

Actual SDK/HTTP/Chromium checks use the real hosted worker and original grid.
They check all four parser formats, bounds/encoding/malformed input, original
warnings, stored values without evaluation, readonly formula input, real canvas
scrolling, sheet switches, changed-file reload, Retry/recovery, narrow fullscreen
and worker retirement. A deterministic tool-free SDK seed creates native history;
subsequent previews preserve it and the provider request log, with no external
browser request. Source, ordinary assembly and installed/manual evidence are
recorded separately below when complete.

Early failures are recorded here: the missing entities notice, an unpatched
FortuneSheet React update loop, nested Immer resolution from a temporary overlay,
and invalid grid geometry caused by the missing optional row height. The first
expanded cohort launch used a wrong working directory and did not start Node.
An expanded GUI assertion initially looked for the original error beneath the success-only grid section; actual failure/Retry display was present. The test now selects the original alert directly and requires a new real worker on Retry. A later exact-byte check exposed the fixture ZIP using current timestamps; fixed authored timestamps make repeated fixture generation deterministic without relaxing byte preservation. Corrections retain the original GUI, exact public patches, two-worker cohort and
existing deadlines. A later cohort catches an existing Office test racing the original file-version watcher: replacing the file can retire its old Retry button before pointer preparation. The test now proves a real Retry read against still-malformed bytes, then recovers through the persistent original reload control after replacing bytes. Product behavior and deadlines are unchanged. Failed attempts are not passing qualification evidence.

This is a readonly preview, not a spreadsheet editor or complete file-viewer
migration. Password-protected/encrypted workbooks, broader real-world format and
accessibility acceptance, rendered HTML, native opening/downloads, other platforms
and complete P0/P1 migration remain open. Existing public MPL/native/Sharp/font
source/rebuild and missing MIT-declaration notice-sufficiency gates remain open.
DSH remains available; this work does not publish a public binary release.

A subsequent environment refresh removed the temporary test environment and ordinary stage. Source/selected bytes remain preserved. Qualification is rerun with a fresh ordinary dependency stage and a dedicated matching QtTest environment. The first fresh run accidentally resolved the virtual-environment Python symlink to system Python, losing QtTest; the corrected executable path preserves the virtual environment. Fresh logs and comparison helpers stay under ignored outputs, separately from immutable releases.
