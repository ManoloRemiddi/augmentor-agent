# Original Harness spreadsheet previews

## Registration, original UI and limits — October 12

The original public DSH spreadsheet registration serves `.xlsx`, `.xls`, `.csv`
and `.tsv` in the existing file sidebar. Its lazy renderer, FortuneSheet grid,
formula bar, sheet tabs, selection/copy controls, loading, Retry, notices and CSS
remain original. Editing and formula recalculation are disabled. Stored formula
results stay stored; missing cached results and unsupported workbook features
remain visible through the original warnings. CSV/TSV cells remain literal text,
including formula-looking strings and leading zeroes.

The public MIT GUI selection adds **twenty files**, bringing **507 to 527**, from
**d743267388641bc76f17c45ce8b4c231aed1d32c**: sixteen spreadsheet modules, the
original FortuneSheet licence and three original FortuneSheet/ExcelJS patches.
**Eighteen are verbatim; two carry marked adaptations.** `parse.ts` uses a fixed
same-origin module worker instead of a Blob worker. `xlsx.ts` omits an absent or
invalid optional default row height; the original multiplication produced NaN
and prevented scrolling in an otherwise valid workbook. Valid point heights
retain the original conversion. All preceding supplier bodies and CSS remain
unchanged; Apache-2.0 dsh-context remains **108 files**, with its separate notices.

The original parser retains **16 MiB**, **250,000 rectangular cells** across
sheets and a **15-second** deadline. The existing authorized complete-byte reader
and its independent **20 MiB** Host cap remain in use. Workbooks parse in a
dedicated browser worker; no Office conversion, agent, tool or provider request
is created. Source/version/authority checks and tab/session/Host lifetimes use
the existing original file viewer. Abort and timeout terminate the real worker.

The worker is one reviewed self-contained module at
`/dsh-excel-worker-0.2.1-alpha.2.mjs`. Its response policy permits only same-origin
scripts, with network and child workers disabled. The application policy is
unchanged. Parser code and the grid remain deferred from initial application
loading. Worker and application graphs both participate in supplier notices and
forbidden-backend/analytics checks.

heights, a deliberately incorrect saved formula result, a missing result and
unsupported conditional formatting. Raw BIFF8 records are independently authored,

literal values and encoding. No private or upstream document fixture is copied.

Actual SDK/HTTP/Chromium checks use the real hosted worker and original grid.
They check all four parser formats, bounds/encoding/malformed input, original
warnings, stored values without evaluation, readonly formula input, real canvas
scrolling, sheet switches, changed-file reload, Retry/recovery, narrow fullscreen
and worker retirement. A deterministic tool-free SDK seed creates native history;
subsequent previews preserve it and the provider request log, with no external
browser request. Source, ordinary assembly and installed/manual evidence are
recorded separately below when complete.

FortuneSheet React update loop, nested Immer resolution from a temporary overlay,
and invalid grid geometry caused by the missing optional row height. The first

The test now selects the original alert directly and requires a new real worker on Retry. This is a readonly preview, not a spreadsheet editor or complete file-viewer

## Repeat the qualified cohort

The exact [58-file cohort](../tests/cohorts/harness-mx.json) is versioned. Run from
source or a separate ordinary assembly with Node 24.19.0 and a prepared matching
QtTest environment; installed releases deliberately omit the test tree. Keep
the virtual-environment executable path, rather than resolving its Python symlink.

```sh
AUGMENTOR_PYTHON=/path/to/prepared-test-environment/bin/python node --input-type=module <<'JS'
import {readFileSync} from 'node:fs';
import {spawnSync} from 'node:child_process';
const {files,concurrency}=JSON.parse(readFileSync('tests/cohorts/harness-mx.json','utf8'));
const result=spawnSync(process.execPath,['--test','--test-concurrency='+concurrency,...files],{stdio:'inherit'});
process.exit(result.status??1);
JS
```
