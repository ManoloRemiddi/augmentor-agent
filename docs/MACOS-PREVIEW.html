Augmentor Agent for Mac

Apple silicon (M1 or later) · macOS 14 or later · early preview

This preview is not signed with an Apple Developer ID or notarized by Apple. macOS requires your explicit approval on first launch. Automatic updates are not available yet. Use your own model account or local model server; model usage may have a cost.

Install and connect

  1. Drag Augmentor Agent Desktop into Applications. Eject the disk image, then open Augmentor from Applications. Keep just this one installed copy.
  2. If macOS blocks it, dismiss the alert and open System Settings → Privacy & Security. Find Augmentor and choose Open Anyway, then confirm Open. Approve only the copy you downloaded from augmentoragent.com. Apple’s instructions.
  3. In Install DSH, enter your provider’s OpenAI-compatible API address, exact model name and API key. For an unauthenticated local server, leave the key blank. Adjust the context size under Advanced model settings if needed. Click Install DSH. Augmentor installs the included engine, connects the model and checks that the agent is ready. Each step appears on screen.
  4. Send a short message. Your conversation and settings stay in your own account. Clicking the app icon opens the window; Fn + Space shows or hides it. Change the shortcut in Settings if your keyboard reserves it.

DSH, the required plugins, Python and Node are included. You do not need to install them separately. Existing DSH users can choose Use existing DSH. Your API key is kept in an owner-only local configuration file; this preview does not use Keychain. No model subscription or model weights are included.

Add the Chrome or Chromium extension

  1. In Augmentor’s three-dot menu, choose Set up browser extension. Choose your browser, then click Prepare browser extension.
  2. Click Copy extension folder address, then Open browser Extensions page.
  3. Turn on Developer mode, click Load unpacked, then press Shift + Command + G in the folder chooser. Paste the copied address and select the folder.
  4. Pin Augmentor in the browser toolbar and open its side panel. It uses the model connection you configured in the desktop app.

Keep the prepared extension folder in Application Support. Chrome Web Store installation is not available for this preview. Company-managed Macs or browsers may prevent manual approval or unpacked extensions.

Preview limits

This release focuses on desktop chat and the matching browser companion. Speech engines and local memory servers need separate configuration. Computer control needs macOS privacy permissions. End-to-end microphone, desktop-control permissions and every model provider have not been qualified. OAuth-only providers cannot be connected through the basic API-key form.

For updates, removal, troubleshooting and the exact release test record, use the Mac preview guide. Do not drag a replacement over the app while Augmentor or its browser companion is working. There is no automatic update service in this preview.
