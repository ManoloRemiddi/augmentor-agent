This collection preserves upstream Qt Base 6.8.2 attribution records, their
referenced license/copyright files, and the release's LICENSES directory.
`collection.json` records the pinned commit, file hashes, accepted upstream JSON
format deviations and exact LicenseId-to-file resolutions. Original texts are
unchanged. All upstream attribution records are retained, including components
that may not be compiled into the macOS wheel.

No unresolved file references remain in this collection. This does not establish
which third-party components were compiled into the wheel, nor cover other Qt
modules. Matching source archives, build provenance, replacement instructions and
public source access are tracked separately in `release/native-sources.json`.
