# Linux Pi package

src/index.ts exports the supported inline Pi extension factory used by the host. It registers the system profile, visible Chromium open, AT-SPI observation and ask-user tools. The existing Python desktop helpers ship in the release. This component is bundled with the Augmentor distribution; it is not published as a separate npm package.
