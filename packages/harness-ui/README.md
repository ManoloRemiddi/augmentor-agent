# Harness presentation utilities

The adapted DSH timeline projection remains MIT licensed, with its pinned public source and original notice in [vendor/dsh](vendor/dsh/SOURCE.md). `src/trajectory-contract.ts` is an independently authored minimal view contract. Neither package includes a DSH session service or agent loop.

The web client uses actual recorded start times and monotonic durations. Missing durations stay markers. Tool pairing includes request identity, and interval focus uses the copied inclusive DSH projection. `scripts/copy-protocol.mjs` includes the complete supplier notice in compiled distributions.
